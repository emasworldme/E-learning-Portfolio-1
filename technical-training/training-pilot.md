# IT Technical Training Pilot — facilitator and evaluation pack
**Status:** Ready-to-run facilitator plan; delivery, audience, assessment and learner feedback **not yet evidenced**.

## Measurable learning outcome
Given a configured Packet Tracer lab with an injected fault, the learner independently identifies the cause, makes a suitable change and demonstrates restored connectivity.

## Pre-assessment (10 min)
Provide the faulty .pkt, without revealing the fault. Ask learner to explain observed symptoms and choose first checks. Record where help was needed; adapt explanation based on baseline.

## Session 1 — facilitated demonstration (45–60 min)
- 0–5 min: safety, scope, outcomes and baseline explanation.
- 5–15 min: model troubleshooting order: physical status → IP/mask → gateway → router → DNS.
- 15–30 min: perform wrong-gateway experiment with think-aloud and paired practice.
- 30–45 min: demonstrate DNS versus IP reachability with paired practice.
- 45–60 min: summary, questions and short retrieval check.

## Session 2 — independent performance (30–45 min)
- Start with an alternate fault, keep answer key hidden.
- Learner independently captures symptoms, tests, cause, correction, and verification.
- Collect anonymized rubric and learner feedback; review guide updates.

## Scoring rubric (0–3 total)
| Criterion | 0 points | 1 point |
|---|---|---|
| Diagnose cause | Missing/wrong cause | Correct root cause with a relevant test |
| Correct configuration | Incorrect/absent fix | Appropriate change applied |
| Verify service | No post-fix test | Evidence of restored IP or name resolution, as appropriate |

Performance threshold for this pilot **proposal**: 3/3; report raw scores and pass rate only after a real session. Provide appropriate support for accessibility without changing scoring criteria.

## Feedback prompts
1. Which diagnostic step was hardest?
2. What should change in the learner guide?

## Reporting template
- Date, format, duration, context, participant count (no invented entries).
- Pre-task starting points and observed support needs.
- Anonymous scores (L01, L02...) and count meeting 3/3.
- Common errors; learner quotes only with consent and deidentification.
- Facilitator guide version BEFORE → AFTER: exact change, reason and validation.
- If an IT/network specialist reviews the lab, list name/role with permission, date, recommendation and implemented correction.

## Claim gate
Only say **“delivered in person and online”** after one real in-person session and one real synchronous online session, with dates and evidence. Otherwise present this as `training pilot design`, not past delivery. Do not imply a professional trainer certification.
