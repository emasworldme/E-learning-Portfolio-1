The project models a fictional global medical-technology service education organisation. MR onboarding, software workflows and remote-support education share an operating model, source controls and regional adaptations. All business data and roles are simulated. No Siemens Healthineers affiliation or approval.

## What is implemented

- Three-language interface and equivalent programme content; language and region are independent controls.
- Strategic brief, customer-journey hypothesis map, target operating model and RACI.
- Four-condition release gate; all conditions are required and labels explicitly say simulation.
- Three learning scenarios; first-attempt answers persist across language and page changes during the current tab session.
- Synthetic capability dashboard with explicit denominators, count bounds and undefined zero-denominator states.
- Conservative first-year time-value model; negative returns are displayed without manipulation.
- Proposed 12-week rollout, risks, dependencies, agile cadence, evidence matrix and Markdown export.

## Run and review

Open index.html in a modern browser; it has no runtime dependency or external asset requirement. Use the language selector, then visit all eight sections. In Governance, leave one box unchecked and verify the release remains blocked. In Learning, answer incorrectly, switch language and verify the first answer is retained. In Measurement, test zero counts and dependent counts. Use Export to download the active language's project brief.

The page holds only temporary tab state; refresh clears it. It does not send learner data or review requests. Notion links require workspace permission and are not public evidence of live client activity.
