A course agent with boundaries.

A local, source-grounded learning coach for an adult education course. It finds passages in approved materials, shows where they came from, and declines questions the sources cannot support.

01 / Learning problem

Answers should be traceable.

Learners need help finding and interpreting course material without treating a chatbot as an authority on grades, personal matters, or unsupported facts. The prototype keeps the knowledge boundary visible.

01 — RECORD

Approved material

A curated JSON corpus of syllabus excerpts, selected slides, handouts, reflection prompts, and case texts. Source IDs and locations stay attached to each passage.

02 — DISCOVERY

Relevant passages

A local lexical retrieval step selects matching excerpts. If the evidence is weak, the agent says so instead of filling the gap.

03 — ASSISTANCE

Learning support

Without an API key, the prototype displays original excerpts. With a server-side key, it can generate a cited answer and falls back to excerpts if citation checks fail.

03 / Scope & next step

A research prototype, not a deployed campus service.

The supplied application runs on a local Python server at 127.0.0.1. It has no login, role-based access, conversation database, or secure multiuser deployment. Before course use, it needs source review, evaluation cases, institutional privacy review, and an authenticated hosting design.

DESIGN

Human oversight

Questions beyond the corpus are directed to the teacher or official channels. The system does not grade student work.

EVALUATE

Test beyond fluency

Measure source accuracy, justified refusal, useful learning prompts, and independent learner decisions.

BUILD

Deployment gate

Review source rights, accuracy, privacy, costs, access control, and operations before making the service available to learners.
