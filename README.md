# Amine Merve Ercan — Interactive Learning Portfolio

A static portfolio for GitHub Pages: 3D project map, Articulate courses, serious-game and MR learning concepts, interactive teaching cases, a course-agent prototype, and an interactive CV with two public PDF versions, verified LinkedIn and Google Scholar profile links, and a guided-inquiry teaching statement.

## GitHub Pages'te yayımlama

1. `merveemirgame-boop` hesabında `merve-learning-portfolio` adında **public** ve **boş** bir depo oluştur. Başlangıç README'si seçme; bu pakette README zaten var.
2. İndirilen ZIP'i bilgisayarında aç. **ZIP dosyasının kendisini veya üst klasörü değil, içindeki tüm dosya ve klasörleri** deponun köküne yükle. Boş depodaki **uploading an existing file** bağlantısını ya da **Add file → Upload files** yolunu kullan. En üstte `index.html`, `app.js`, `style.css` ve klasörler görünmeli.
3. Dosyaları `main` dalına commit et.
4. Depoda **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save** seç.
5. Pages ekranında yayımlama başarılı göründüğünde `https://merveemirgame-boop.github.io/merve-learning-portfolio/` adresini aç.

Bu adres GitHub yayımlamayı tamamlamadan önce etkin sayılmaz. Bir sayfa 404 verirse `index.html` dosyasının depo kökünde ve Pages kaynağının `main` / `(root)` olduğundan emin ol.

## İçerik notları

- `cv/` içindeki iki PDF herkese açık paylaşım için hazırlanmıştır. Akademik CV'deki üçüncü kişilere ait referans iletişim bilgileri çıkarılmıştır.
- Course-specific AI agent şu anda yalnızca yerel davranış prototipi ve vaka anlatımıdır. Güncellenmiş ajan sağlandığında ilgili bölüm değiştirilmelidir.
- Articulate paylaşım bağlantıları üçüncü taraf sayfalara açılır. `downloads/` klasöründeki SCORM paketi ayrıca indirilebilir.
